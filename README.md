# Clone To Steal Eggs GUI
a roblox exploit for the game [clone to steal eggs](https://www.roblox.com/games/76943966208523/Clone-to-Steal-Eggs) I made with my brother.
## features:
- autocollect eggs
- notify when eggs spawn
- very barebones, basic ui
- easy to use
## loadstring:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/starl1ghtscripter/ctse-gui/refs/heads/main/gui.lua"))()
```
